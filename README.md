# Cadastro acadêmico

Atividade de Laboratório de Desenvolvimento Web desenvolvida com Next.js, TypeScript e App Router.

O sistema permite:

- consultar e cadastrar alunos;
- consultar as disciplinas do curso;
- consultar e cadastrar matrículas.

Os cadastros são mantidos no estado da aplicação e no `localStorage` do navegador.

## Como executar

```bash
npm ci
npm run dev
```

Depois, acesse [http://localhost:3000](http://localhost:3000).
